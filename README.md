# Conexões SI

Mapa interativo das disciplinas e possibilidades de carreira do Bacharelado em Sistemas de Informação do IFMG, campus Ouro Branco. É um projeto estudantil independente.

[Abrir demonstração no GitHub Pages](https://vitorhrm.github.io/SADtrab/)

## O que explorar

- Disciplinas obrigatórias e optativas, organizadas por período.
- Relações entre disciplinas e carreiras, com comparação e favoritos.
- Sugestões baseadas nas matérias selecionadas, com três pontos para vínculos diretos e um ponto para matérias de apoio.

## Executar

Abra `index.html` em um navegador ou sirva a pasta com `python -m http.server 8000` e acesse `http://localhost:8000`. O projeto usa HTML, CSS e JavaScript e dispensa compilação.

## Dados e critérios

`data.js` reúne os dados do mapa, `dados.json` oferece a versão exportável e `app.js` organiza a exploração. A seção **Fontes** da interface reúne o PPC, o ementário e a matriz curricular, incluindo notas sobre divergências entre os documentos. As relações de carreira foram organizadas para a ferramenta. Consulte a coordenação para saber qual matriz se aplica à sua turma.
